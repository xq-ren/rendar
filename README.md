# Rendar

Rendar — the name being a mix of my nickname **"Ren"** and the word **"calendar"** — is basically exactly what the name says.
It's my personal calendar, made because I don't really like any of the calendar apps I've tried. There's always something missing, something I wish worked differently, something about the design that bothers me, or a feature I want that's locked behind a paywall.

So instead of continuing to complain about it, I'm making my own.  That also means I get to add whatever features I want and, most importantly, be completely in control of the design. :3

## Most Important to Me
* Calendar month and week views
* Event creation and management
* Reminders
* Stuff to remember
* Recurring events
* Categories
* Design customization
* Web interface
